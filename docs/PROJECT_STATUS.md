# 项目启动状态

基准：`开一局_MVP产品需求文档_v0.1.docx`，2026-09-15。

## 本轮里程碑

先交付成语炸弹端到端垂直链路，对应 PRD 第 2–5 天的技术主线，并提前实现其中部分断线、安全和输入交互要求。未将全部十天的 MVP 工作标记完成。

决策：

- 保留 PRD 的 Next.js + 独立 Node.js / Socket.IO 架构，不将内存房间托管为无状态页面函数。
- 使用单进程同步状态机，不在判题与状态提交之间等待外部服务。
- 数据文件默认本地 SQLite，访客凭证至少 128 位；当前使用 256 位。
- 仅开启成语炸弹。其他玩法、卡片和表情沿用 PRD 的允许降级顺序。
- 不伪造人工词库审核、真实群试玩或微信实机验收结论。

## 规则冻结

| 规则 | 实现 |
| --- | --- |
| 人数 | 2–8 人，含观战者 |
| 生命 | 每位参赛者 2 条 |
| 回合 | 首 60 秒每回合 12 秒，随后 9 秒；开始时锁定 |
| 整局 | 180 秒，整局截止先于回合截止判定 |
| 顺序 | Fisher–Yates 随机顺序，只随机一次，之后循环 |
| 答对 | +1 正确答案、1 秒反馈、换人换题 |
| 答错 | 私有 ack，继续作答，不重置时间 |
| 超时 / 放弃 | -1 生命，2 秒反馈 |
| 题面 | 至少 8 个本局未使用常用答案，尽量避开最近 3 题；扩展词库其他合法词也可答 |
| 重复 | 以标准 answerId 去重 |
| 结束 | 最后幸存者、到时按生命及正确数、同分并列 |
| 内容故障 | content_exhausted，无冠军 |
| 退出 | 不参与冠军比较，对手退出胜利单独标记 |
| 断线 | 不暂停，30 秒保留，超时移除 |
| 房间回收 | 全员离线 30 秒；无操作 14 分钟提醒、15 分钟关闭 |

## 自动化覆盖范围

单元测试覆盖昵称、容量、房主权限、全员准备、倒计时取消、观战、成功/失败作答、actionId 冲突与重试、旧回合、deadline 相等、全局超时、生命扣减、回合时长、复玩、重连、房主转移、移除禁入、内容耗尽、答案限流、SQLite 凭证哈希及清理。

Socket.IO 集成测试通过本地入口连接多个独立访客，覆盖真实协议的建房至复玩、单控制连接接管、Origin 拒绝和隐私快照。这是协议联调，不等价于“两名真人浏览器已试玩”。
